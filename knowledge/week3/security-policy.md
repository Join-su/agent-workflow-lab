# NoriWorks IT 변경 및 보안 예외 정책

문서 ID: ENG-CHANGE-001  
적용 대상: 운영 환경의 애플리케이션, 인프라, 접근 권한, 보안 설정 변경  
최종 검토일: 2026-09-01

## 1. 일반 변경

일반 변경 요청에는 변경 목적, 영향 범위, 검증 방법, 롤백 방법을 기록한다. 배포 전에는 담당자가 변경안을 검토하고, 서비스 중단 가능성이 있으면 영향 받는 팀에 알린다. 이 실습 서비스는 변경안을 검토할 뿐 실제 명령을 실행하거나 배포하지 않는다.

## 2. 정책 우회와 보안 예외

보안 제어를 **무시**, **우회**하거나 규정 **예외**를 요청하는 변경은 자동 승인할 수 없다. 요청자는 사유, 영향, 보완 통제, 예상 종료 시점을 기록해야 하며, 승인 권한자가 사람 검토로 판단한다.

비밀번호 정책 해제, MFA 해제, 방화벽 규칙의 광범위한 개방, 감사 로그 중지는 보안 예외로 취급한다. 이런 요청이 긴급하더라도 운영자는 정책을 건너뛰지 않는다.

## 3. 긴급 변경

서비스 장애 완화처럼 즉시 조치가 필요한 긴급 변경도 가능한 범위에서 변경 전 기록을 남긴다. 긴급 배포 또는 긴급 권한 변경은 사후 첫 영업일 내에 승인자 검토와 변경 기록 보완이 필요하다.

## 4. 결과 해석

`human_review`는 변경이 거절됐다는 뜻이 아니라, 승인 권한자의 판단과 기록이 필요하다는 뜻이다. `done`은 실습 워크플로의 검토가 끝났다는 뜻일 뿐 배포 실행 또는 보안 예외 승인을 뜻하지 않는다.
