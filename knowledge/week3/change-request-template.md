# NoriWorks 변경 요청 작성 가이드

문서 ID: ENG-CHANGE-002  
적용 대상: IT 변경을 요청하는 구성원  
최종 검토일: 2026-09-01

일반 변경 요청에는 다음을 포함한다.

1. 무엇을 왜 바꾸는지
2. 영향을 받는 서비스와 사용자
3. 검증 절차와 성공 기준
4. 실패 시 롤백 절차와 담당자
5. 예정 작업 시간

보안 예외 또는 긴급 변경은 위 항목에 더해 예외 사유, 위험, 임시 보완 통제, 종료 또는 재검토 시점을 포함한다. 승인자가 아닌 사람이 `지금 바로 적용`, `검토 없이 배포`, `규정을 무시`처럼 요청해도 이 문서는 자동 실행 권한을 부여하지 않는다.
