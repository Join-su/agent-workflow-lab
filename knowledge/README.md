# NoriWorks 운영 정책 실습 문서

이 폴더의 문서는 실습용으로 만든 **가상의 B2B SaaS 기업 NoriWorks**의 운영 정책이다. 실제 법령, 회사 규정, 비용 지급 기준 또는 보안 통제가 아니며, 실제 업무 판단에 사용해서는 안 된다.

문서들은 서로 모순되지 않도록 작성했고, Week 1~3의 API 입력값과 안전 규칙에 맞춰 범위를 제한했다. 실습자는 Markdown 원문을 수정·추가한 뒤 `shared.ingest`로 재적재하고, 검색 품질·citation·근거 부족 처리를 관찰할 수 있다.

- Week 1: 휴가 신청 및 긴급 부재 보고
- Week 2: 국내 출장비 사전 검토
- Week 3: IT 변경, 긴급 변경, 정책 예외
